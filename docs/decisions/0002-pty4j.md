# 0002. pty4j is the pseudo-terminal

Recorded: 2026-11-07, from the reasoning in the code and the old AGENTS.md.

## Context

Java has no PTY API, and the platforms disagree fundamentally: `forkpty` on Unix, ConPTY (or
winpty) on Windows.

## Decision

Use pty4j. One jar carries macOS, seven Linux architectures and Windows ConPTY + winpty.

## Consequences

- There is no per-OS native build step.
- Its natives survive JPMS packaging by an accident of naming (`native` is a reserved word, so the
  resource directory maps to no package); a rename upstream would break only the packaged build.
  See [gotchas.md](../gotchas.md).
