# Full review — 2026-10-27

Reviewed at `5803a3f` (branch `fix/full-screen-title-bar`, clean) on Debian 13 / GNOME on Wayland
(XWayland), JDK 25.0.1, JavaFX 27.0.1. Linux only; macOS and Windows findings are from code.

How: `./mvnw verify` (859 tests, 0 failures, coverage floors met); `-Pdist` app image and `.deb`
built locally (the `.rpm` step fails here only because `rpmbuild` is not installed); the released
0.12.0 debs' control files read through a range request; the packaged app run from the extracted
`.deb`; fifteen `DevCapture` runs against scratch `TERMINA_CONFIG_DIR`s; four independent code passes
(renderer/input, window/panes, settings/themes/shell/PTY, sync/update/build/release).

**Verified** means seen happen in a run, or traced to a probe result. **From code** means read, not
driven. Items fixed by the 2026-10-20 review were spot-checked and not re-reported; no regressions
were found in them.

---

## 1. Verdict

The app is in good shape for a 0.12. It builds clean, the packaged image starts, and the decisions
that are hardest to get right — focus guard, chords as a scene filter, git hardening in sync, paste
sanitising, OSC 52 caps, tab disposal off the list — are right and well defended. The worst problems
are not in the terminal but **around** it:

1. **The released `.deb`s cannot be installed on Debian 12 or Ubuntu 22.04** (§3.1).
2. **A remote `file://` link is opened anyway** — on Windows an SMB fetch and NTLM leak (§4.1).
3. **A hand-edited backslash in `settings.properties` stops the app starting** (§5.1).
4. **The palette leaks chords to the menu accelerators: Ctrl+Shift+W in the palette closes the tab
   behind it** (§2.1, verified).
5. **The macOS bundle will ship with a broken signature from 1.0.0 on** (§3.4).

Fix those five first; each is small.

## 2. Found by driving the app (verified)

### 2.1 Chords typed into the palette (and find bar) fall through to the menu accelerators
`TerminalWindow.onKeyPressed` returns early while the palette is open (`:2844`) and yields to a
focused text field (`:2851`), but the menu items still carry live accelerators, which JavaFX runs for
any key press nobody consumed. **Run:** one extra tab, palette open, `C-S-w` fired at it →
`terminals=1` (control run with `C-n`: `terminals=2`). The same path should paste the clipboard into
the shell on Ctrl+Shift+V in the find bar — the exact thing `yieldsToTextField` exists to prevent
(not driven, to keep the clipboard out of it). Fix: make menu accelerators display-only (one
dispatch route for one table), or consume after yielding.

### 2.2 The cursor drifts one cell right per astral character on the line
JediTerm's cursor X is a buffer *slot* (a surrogate pair counts two); `drawCursor` treats it as a
column (`TerminalView.java:1142`, also `:1146` prediction, `:1165` glyph redraw, `:2691` OSC 133
column). **Run:** `printf 'A📁B📁C'` — text occupies five cells, cursor drawn at column 7. Anyone with
an emoji or a Nerd Font Material icon (U+F0000+) in their prompt sees the cursor detached from where
typing lands. Fix: `ColumnMap.columnAt(text, cursorX)` to draw; use `cursorX` directly as the slot.

### 2.3 The tab strip breaks with many tabs in a narrow window
520 px, seven tabs (`tabWidths=[77 ×7]` in a 520 strip): the first tab is clipped at the left edge,
the active tab's label is hidden, and JavaFX's overflow `▾` sits on the active tab's close button,
splitting its underline. The 10-20 fix (§2.5) covered `+` against the last tab, not overflow. Shrink
the minimum width, or let the strip scroll the selected tab into view without the stock overflow
control.

### 2.4 Inactive panes and unfocused windows draw the same solid cursor
`drawCursor` has no focus state. With three panes all three show a filled block, so the only cue for
which pane takes keys is the thin outline. Every mainstream terminal draws a hollow box when the
pane or window is unfocused; it is the strongest focus cue a terminal has.

### 2.5 No inner padding
Output starts at x=0, flush against the window edge (`pkg.png`, `tabs.png`). Most terminals default
to a few pixels and make it a setting.

### 2.6 Smaller things seen
- **Settings search box looks empty.** It has a prompt (`settings.search`), but it is focused on
  open and Modena hides prompt text on focus, so the user sees a bare box at the top of the window.
- **Shortcut reference lists "New Tab With Profile 1…9"** — nine rows on a machine with one profile.
- **Light theme + Powerline prompt** still renders the user segment black-on-black. Faithful to the
  palette (as `ThemeTest` pins), but worth a line in the theme's description.
- **Packaged app: ~340 MB RSS** with one tab, 5.4 s from launch to capture exit with the AOT cache.
  Not a bug; the number to watch against native terminals.
- **Dev builds report as 0.12.0 and "up to date".** `master` keeps `<version>0.12.0</version>` after
  the release; bump to `0.13.0-SNAPSHOT` after tagging so bug reports from source builds are
  distinguishable.

## 3. Packages, CI and release

### 3.1 The released debs depend on `libasound2t64` — uninstallable on Debian 12 / Ubuntu 22.04 (verified)
Both v0.12.0 debs (x64, arm64) declare `Depends: libasound2t64, …`. That package exists only on
Debian 13+ and Ubuntu 24.04+, where the 64-bit `time_t` transition renamed it; on bookworm, jammy,
Mint 21 and friends `apt install ./termina…deb` refuses. jpackage derives it from the build host
(`ubuntu-latest`). It comes from `libjsound.so` in `java.desktop` — sound Termina never uses.
Fix: drop `libjsound.so` from the image, or post-process the control file to
`libasound2t64 | libasound2`; and check on a bookworm container in CI.

### 3.2 The debs do not declare GTK, GL or fontconfig (verified)
JavaFX's natives are extracted from the module jars at run time (to `~/.openjfx/cache`), so jpackage
never sees `libglassgtk3.so` and declares none of its dependencies. On a minimal or non-GNOME
install the package installs and the app fails at start. Add `--linux-package-deps` for
`libgtk-3-0`, `libgl1`, `libfontconfig1` (and the rpm equivalents).

### 3.3 No licence notices reach any installed copy (verified)
`NOTICE` and `LICENSE` are in neither the jar nor the packages; the deb's `copyright` says
`License: Unknown`; About says "See NOTICE". NOTICE also omits JavaFX (GPLv2+CPE), Kotlin stdlib,
Jackson, SLF4J and the provenance of the Symbols Nerd Font's glyph sets (its bundled `LICENSE` is the
patcher's MIT text only). Ship both files as resources and via `--license-file`; complete NOTICE.

### 3.4 macOS: the bundle is not re-signed once the version reaches 1.0 (from code)
AOT training adds `termina.aot` after jpackage signs; `fix-mac-bundle-version.sh` re-signs, but exits
early when `current == version` (`:23`), which is true for every version ≥ 1.0. From 1.0.0 the DMG and
cask ship broken seals — "damaged and can't be opened" rather than the expected Open Anyway. CI's
unquarantined smoke test would not notice. Re-sign whenever AOT ran.

### 3.5 Release artefacts are never checked
`release.yml` builds with `-DskipTests` and runs none of CI's checks (smoke test, deb contents,
`TERMINA_REQUIRE_AOT=1`), and a `v*` tag is not gated on CI. `linux-arm64`, `macos-x64` and the MSI
are built for the first time on release day. The `.rpm` is never inspected anywhere.

### 3.6 Smaller
- **CI's "the shell ran the command" smoke check is vacuous** on Linux/macOS: the prompt
  (`runner@…`) and the `Picked up JAVA_TOOL_OPTIONS` line both contain `$me`. Grep for a line equal
  to `$me` inside the screen block.
- **The icon regression `packaging/linux/NOTES.md` warns about is still unchecked** — CI never
  compares `lib/Termina.png`'s hash.
- **Supply chain:** `contents: write` is workflow-wide in `release.yml`, so every build job holds a
  write token while running Maven against a non-Central repository; `jreleaser/release-action@v2` is
  a mutable tag that receives `PACKAGES_TOKEN`. Pin by SHA; scope `write` to the publish job; consider
  `actions/attest-build-provenance`. `choco install wixtoolset` is unpinned against a hard-coded 3.14
  path; the Maven wrapper has no `distributionSha256Sum`.
- **Pre-release tags can never build:** `derive-versions` hands `0.13.0-rc1` to jpackage, which
  rejects it, though `jreleaser.yml` is set up to publish them.
- **AOT training uses the developer's real config** (`aot-train.sh` sets no `TERMINA_CONFIG_DIR`):
  `-Pdist` on a dev machine starts the user's shell, may start sync, and writes
  `updates.lastCheckEpochMs` into their settings.
- **Linux integration:** no `termina` on `PATH` (only `/opt/termina/bin/Termina`), no
  `x-terminal-emulator` alternative, no AppStream metainfo (so no listing in GNOME Software / KDE
  Discover), no `X-TerminalArgExec=-e` for `xdg-terminal-exec`. The README's "desktops offer it where
  a terminal is wanted" depends on the first two.

## 4. Security (from code unless noted)

### 4.1 A remote `file://` link is opened through `HostServices`
`LinkPaths.fromFileUri` (`:67`) returns null for a non-local host ("not ours to open"), but
`TerminalView.openLink` (`:1676-1683`) then falls through to `openUrl` with the same URL. On Windows
that is ShellExecute on a UNC path: one click on an OSC 8 link with innocent text fetches over SMB
(leaking an NTLM hash) and may run the file. Hovering alone already stats `file:////host/share/x`
(empty host counts as local) and `\\host\share\x` tokens. Fix: refuse non-local `file:` outright, and
refuse UNC before any `Files.exists`. (Code path verified; Windows behaviour inferred.)

### 4.2 A hostile `.terminal` file hangs or crashes the app
`BinaryPlist`'s `reading[]` guard stops cycles but not shared references: object *i* = `[i+1, i+1]`
doubles per level (a 212-byte file at depth 24 took 1.2 s; ~300 bytes runs for hours). A 200k-deep
chain (1.8 MB, under the 4 MB cap) throws `StackOverflowError`. The import runs on the FX thread and
catches only `ThemeImportException`/`IOException`. (Verified by probe.) Memoise by object index,
bound depth and total visits, run the import off the FX thread.

### 4.3 Any exception in an OSC listener ends the session
Listeners run inside the emulator's `getChar()`; JediTerm rethrows, and `runEmulator`'s `finally`
closes the pane. `onDirectoryReported` (`TerminalView.java:2624`) calls `Path.of` uncaught, so on
Windows `printf '\e]7;file:///C:/a%2Ab\a'` — from any program or remote host — closes the pane.
Wrap `listener.osc` / `listener.keyboardMode` in a logging try/catch.

### 4.4 The shell inherits the parent terminal's identity
`ShellLauncher` (`:207-216`) removes only `_`. `TMUX`, `TMUX_PANE`, `STY`, `KITTY_WINDOW_ID`,
`WEZTERM_PANE`, `ITERM_SESSION_ID`, `LC_TERMINAL`, `WT_SESSION`, `VTE_VERSION`, `TERMINFO`,
`COLUMNS`/`LINES` and `TERM_PROGRAM_VERSION` pass through: launched from tmux, `tmux` inside refuses
to nest; launched from kitty, image tools speak kitty graphics into Termina. Scrub them and set
`TERM_PROGRAM_VERSION`.

### 4.5 Filesystem stats on the FX thread under the buffer lock
Link hover (`TerminalView.java:1576-1601`) calls `Files.exists` inside `buffer.lock()`; OSC 8 links
are stat'ed on every mouse move. A hung NFS/sshfs/autofs path under the pointer freezes UI and
emulator together. Copy the text under the lock, stat after.

## 5. Correctness (from code unless noted)

### Settings and profiles
1. **`Settings.load` catches only `IOException`** (`:177-184`). A malformed `\uXXXX` throws
   `IllegalArgumentException` out of `App.start` — the app never opens (verified by probe and by
   reading). Other backslashes are silently eaten: `C:\Windows\System32\wsl.exe` loads as
   `C:WindowsSystem32wsl.exe`. The file is documented as hand-editable and Windows paths are what
   people will type. Catch everything, back up a file that failed to load before the next save
   overwrites it, and consider reading it as UTF-8 (`load` reads ISO-8859-1, so `/home/josé` comes
   back mangled).
2. **Two processes clobber each other's settings.** No single-instance lock; each process rewrites
   the whole file from its own memory on every `put` and on window close. Change the theme in one,
   close a window of the other, the change is gone — and the stale `keys.*` may then sync out as a
   local edit. The temp name is a fixed `settings.properties.tmp`, so concurrent saves race on it.
   Re-read and merge before saving, under a lock, with a per-process temp name.
3. **Deleting a profile leaves its style, default and hidden state behind** for the next profile
   that gets its id: delete "New Profile" that was the default with a theme, click Add — the new one
   is silently the default and themed. Adding while a user profile is hidden selects the hidden one
   for editing (`SettingsWindow.java:1740`, `ShellProfiles.java:286`).
4. **The system shell can appear twice** when `$SHELL` and `/etc/shells` spell it differently
   (`/usr/bin/zsh` vs `/bin/zsh`): `merge` (`:166`) compares commands textually though `onUnix` has the
   real paths.
5. **On Windows with no WSL distributions**, `wsl --list --quiet` prints an explanation, not
   nothing, and each line becomes a menu entry. (Depends on wsl.exe; unrunnable here.)

### Windows, tabs and panes
6. **A reordered tab loses drag, double-click rename and pane drop.** `moveTab` (`:1364`) removes and
   re-adds, and `TabPaneSkin` builds a new header; `installTabDrag` runs only from `addTab`.
   (Verified against the 27.0.1 bytecode.)
7. **Every closed window leaks** — `windows.addUpdateListener(this::refreshUpdateItem)` (`:2559`)
   is never removed. The stage, scene, palette and closed-tab history live for the life of the app,
   and an update notice calls into dead windows.
8. **Close Others / Close to the Right, then Reopen, comes back out of order** (`[A,B,C,D]` →
   `[A,B,D,C]`). Push rightmost first.
9. **Closing a full-screen window saves the screen as its size** (`trackGeometry` skips maximized,
   not full screen). Next launch: a screen-sized window at 0,0. Touches the current branch's area.
10. **A cancelled pane drag leaves `draggedPane` set**; a later drop from another window moves the
    stale pane. Clear on `DRAG_DONE`.
11. **The tab header's context menu is not an overlay to `FocusGuard`** (`overlayWantsKeys`,
    `:371-385`), the "dismissed on the way to being shown" family. Drive a right-click on a tab.
12. **When even the default shell cannot start, the app exits silently** — the error alert is owned
    by the window that closes with it.
13. **`swallowNextTyped`** is set after a chord's action returns; if that action ran a modal that was
    dismissed with the mouse, the next real character is eaten.
14. **`PaneGroup.active()` is declared non-null and returns null** in the window between `detachPane`
    emptying a group and its tab going; `closeActivePane` would throw there.

### Renderer, search and input
15. **Search keeps the *oldest* 1000 matches** (`ScrollbackSearch.java:104`, scanning from
    `-history`). In a long build log, matches on screen are not highlighted and the initial match is
    far up in history. Scan newest-first.
16. **Search re-scans everything per keystroke**, copying up to 200k rows under the lock on the FX
    thread, and again every 250 ms during output. Debounce; stop early.
17. **The single-`fillText` fast path desyncs at zero-advance BMP code points** (combining marks
    without an NFC form, ZWJ, VS16 in `⚠️`): the rest of the run draws one cell left per mark.
    Exclude Mn/Me/Cf and U+FE00–FE0F from `CellWidth.isOneCellPerChar`.
18. **`scrollOrigin`/`selectionAnchor` are read-modify-written on the FX thread without the lock**
    while the emulator thread shifts them under it; wheel-scrolling during output can jump.
19. **A mouse release is reported for a press the program never saw** (link open, menu dismissal,
    Shift bypass). Track whether the press was reported.

### Sync and update
20. **A sync retry overwrites newer remote edits.** Received values are applied but `BASE_REF` does
    not move, so on the retry after a lost push race they count as local changes and revert the
    third machine's edit; after a lasting `PUSH_FAILED`, every key ever received counts as local
    forever. `received` also accumulates duplicates. No test covers the retry path.
21. **Sync can report success with nothing committed** when a global `core.excludesFile` or the
    remote's `.gitignore` matches. Use `add --force -- <paths>`.
22. **An `Error` in the sync worker leaves it "Syncing…" until restart** — no `try/finally` around
    `finished`.
23. **The update check has no timeout on the body** (`HttpRequest.timeout` covers headers only); the
    single-thread executor then never answers a manual check.

## 6. UX, keys and i18n

- **Default chords take keys the shell owns**, against the project's own rule: the palette is
  `Alt+X` (Emacs/zsh `M-x`, `execute-named-cmd`); Settings is plain `Ctrl+,` off macOS. On macOS,
  New Tab With Profile 3/4/5 is `Cmd+Shift+3/4/5` — the system screenshot keys, so they never fire
  yet are advertised.
- **Reopen Closed Tab does not cover panes or windows**: closing a pane by chord, or a whole window,
  is unrecoverable.
- **French shows doubled apostrophes** (`n''est`, four keys) and one Italian key: `tr()` returns the
  raw MessageFormat pattern. (Verified in `messages_fr.properties:235`.)
- **`settings.defaultProfile.desc` says "Ctrl/Cmd+T"** in every language; off macOS it is
  Ctrl+Shift+T and it is rebindable — use `chordOf`.
- **English in localized UI**: theme import errors, `" (imported)"`, `"Imported"`, `"Default Shell"`,
  `"Command Prompt"`.
- **Imported theme names collide**: anything with no Latin letters slugs to `theme.properties`;
  "Gruvbox (Dark)" and "Gruvbox Dark" share a file; a Windows Terminal import reports both of two
  colliding schemes as imported.
- **A UTF-8 BOM breaks extensionless imports** (Ghostty, Alacritty files from Windows editors).
- Menu items are found by translated label in `file/edit.setOnShowing`; `itemsById` exists.

## 7. Features

The October work closed most of the "first week" gaps; the landscape doc's matrix is accurate. What
remains, in the order a switching user would notice:

1. **Focus cues**: hollow cursor when unfocused (§2.4), optional cursor blink (held back since
   10-20), inner padding (§2.5). Cheap, visible in the first minute.
2. **Install on the distro they have** (§3.1–3.2) and a `termina` command plus
   `x-terminal-emulator` registration. Without these the Linux packages are effectively Debian 13 /
   Ubuntu 24.04 only.
3. **Grapheme clusters and underline styles** (curly/dotted/coloured — used by Neovim diagnostics).
   §2.2 and §5.17 are the same family: the renderer and JediTerm disagree about what a cell is.
4. **Session restore** — reopening the last windows, tabs, splits and directories on launch.
   `ClosedTabs` already captures a split tab's layout.
5. **Ligatures, then an image protocol** — as the capabilities doc says, a spike first.
6. **Scripting / multiplexing** — power-user tier; defer.

## 8. Structure

- **`TerminalWindow` (3.2k lines) has clear seams**: tab strip (~600: headers, drag, tooltips,
  marks), pane operations (~250), command table and bindings (~700), chrome (HeaderBar, menus, full
  screen, geometry), dialogs, and ~400 lines of `*ForCapture` probes that could sit behind one probe
  object.
- **Two dispatch routes for one binding table** — the scene filter and live menu accelerators —
  are the root of §2.1. Make accelerators display-only.
- **Tab headers are skin-owned and rebuilt.** Anything attached to them wants one "re-decorate
  headers" call after every list change, not hand-placed retries (§5.6).
- **Long-lived registrations have no removal path** (§5.7). A per-window `onDispose` list would
  make the next one easy.
- **`com.termina.ui` is 29% covered** (of 7,699 lines) against 75–100% elsewhere. The rule
  "extract the decision, then test it" is the way up; §5.8 (`ClosedTabs` order) and §5.15 (search
  order) are two decisions that are not yet extracted.
